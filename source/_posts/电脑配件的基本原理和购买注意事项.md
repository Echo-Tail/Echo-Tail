## 主机配件

主机配件一共是 8 个，分别是：

+ 中央处理器 CPU
+ 显卡 GPU
+ 主板
+ 内存
+ 硬盘
+ 散热
+ 电源
+ 机箱

### CPU

当前市面上我们能买到的 CPU 都是英特尔或者是 AMD 公司生产的。

**英特尔**

现在英特尔公司在市面上主要有两个系列，分别是**酷睿系列**和**志强系列**，至于早期的奔腾系列和赛扬系列现在基本上绝迹了。酷睿系列是它的消费级 CPU，它是专门面向个人电脑设计的，也是我们用的最多的 CPU。志强系列是服务器的 CPU，它不是面向个人电脑设计的，但它胜在便宜核多能超频。但个人电脑不推荐安装志强系列 CPU。

酷睿系列 CPU 命名规则：

+ I3-13100F
+ I5- 9600K
+ I7-13700KF
+ I9-13900KS
+ I9- 9900XE

前面的 I3、I5、I7、I9 代表的是 CPU 的级别，再后面的 1-2 位则是 CPU的代数，如 13、9 代，代数越大，发布时间就越近，性能也就越好，后面的三位则表示性能水平，如 100、600、700、900，在代数一定的情况下，数组越大性能越强，同样代数的 CPU 级别越高性能越强。比如 I3-13100F < I7-13700KF。但跨代就不行了，比如 I5- 9600K < I3-13100F，具体的性能可以参考 CPU 天梯图。CPU 的后缀代表的意义是：

+ F - 没有核显
+ K - 可以超频
+ X/E - 当代最强旗舰（12代前）
+ S - 当代最强旗舰（12代后）

**AMD**

AMD 系列同理，它也分消费级 CPU 锐龙和服务器的 CPU 骁龙，和 intel 一样不建议买服务器的 CPU，所里这里只介绍锐龙。

锐龙系列 CPU 命名规则：

+ R3-3100
+ R5-5600G
+ R7-7700X
+ R9-7950X

锐龙的命名规则和酷睿非常相似，R3 R5 R7 R9 对应 intel 酷睿的 I3 I5 I7 I9，也是数字越大，级别越高。后面的数字第一个代表代数，后面的三个数代表性能水平，后缀 X 代表可以自动超频，不带 X 代表只能手动超频。CPU 的散片和盒装的性能是一样的。

总的来说同价的 CPU ，AMD 的综合性能和纸面数据要略高于 intel 的 CPU，大部分的生产力工具 AMD 的效率也要高一些，但 intel 的游戏性能要略高于 AMD。

办公加轻度游戏，R5 的核显版本够用，如果是游戏玩家，清点预算，建议 CPU 的预算是显卡的 1/2。

如果你的需求是用来剪辑视频和 3D 渲染，那么好的 CPU 比好的显卡更重要，多核心多线程的 CPU 能跑出更快的渲染速度。

如果你的需求是用来跑 AI ，那么就需要更好的 英伟达显卡，对于 CPU 基本上没什么要求。

### 显卡

显卡的作用是控制电脑的图像输出，而现在市面上能买到的显卡核心都是英伟达和 AMD 公司生产的，他们的官方命名和 CPU 类似。也是分为级别和代数、性能水平、以及后缀时间关系。一般同价位的 AMD 和英伟达的显卡，AMD 的纸面数据是要强一些的。但是英伟达公司发家早，大部分的游戏对英伟达的显卡优化做的更好，所以综合游戏性能可以说是五五开。
